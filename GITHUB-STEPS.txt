Build on GitHub (no installs needed)
====================================
1. Go to github.com, sign in, click "+" (top right) -> New repository.
   Name it uraniumsnack, keep it Public (or Private), click Create repository.
2. Click "uploading an existing file". Unzip this project, then drag EVERYTHING
   inside the uraniumsnack folder (build.gradle, settings.gradle, gradle.properties,
   src, .github, etc.) into the page. Click "Commit changes".
   - If the ".github" folder didn't upload (hidden folders sometimes get skipped):
     click Add file -> Create new file, type  .github/workflows/build.yml  as the
     name, paste the contents of build.yml, and commit.
3. Click the "Actions" tab. A build starts automatically (or pick "Build mod" ->
   Run workflow). Wait ~3-5 minutes for the green tick.
4. Click the finished run, scroll to "Artifacts", download "uraniumsnack-jar".
   Unzip it - inside is uraniumsnack-1.0.0.jar. Put that in your mods folder.
5. Delete the old edibleuranium-1.0.1.jar from your mods folder.

If the run shows a red X, open it, click the "Build" step, and send me the error text.
